# 비동기/TPS 전환 검증

- 독립 적대적 리뷰 2인 승인. 리뷰 중 발견한 동시 디버그 호출 기록 혼합과 인증키
  마스킹 전 오류 분류 회귀를 수정하고 재검증했다.
- 전체 오프라인 147개 및 14개 subtest 통과. 커버리지 91.45%.
- Ruff/mypy/compileall 통과.
- live 종로구 측정정보: 최초 실행 1개 연결 오류/1개 성공. 같은 두 테스트를 다시
  실행해 2개 모두 실제 관측 행과 필드 검증에 통과했다. HTTP 403은 발생하지 않았다.
- live 범위는 `station_measurements` 한 엔드포인트이며 전체 공급자 API 성공을
  의미하지 않는다. 나머지 계약은 기존 fixture와 mock 기반 오프라인 검사로 검증했다.
