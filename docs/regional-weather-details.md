# 행정구역별 날씨 대표값·유가 평균과 날씨 상세

## 표시 계약

- 줌8 미만: 시도별 요약. 줌8 이상12 미만: 시군구별 요약. 줌12 이상: 기존 지점 클러스터와 상세 선택 유지.
- 날씨는 저장 역주소의 시도/시군구로 전체 위치 카탈로그를 묶고 좌표 중심에 가장 가까운 실제 지점을 대표로 선택한다.
  이름·중기예보 지역코드로 행정구역을 추정하거나 서로 다른 기상 코드를 평균내지 않는다. 대표 마커에는 지역명과 실제 대표 지점이 표시된다.
  현재 좌표와 다른 역주소는 제외하며 미확인 지역은 확대 안내를 제공한다.
- 유가는 행정구역·출처·유종별 최신 양수 가격을 SQL에서 집계한다. 화면 bbox와 marker limit으로 평균 표본을 자르지 않는다.
  좌표 미확인 주유소도 지역/유효 가격이 있으면 평균에 포함하며 지역 마커 중심은 좌표가 있는 지점으로 계산한다.
  지역 중심이 화면 안에 있는 요약만 반환한다. 검색/출처/유종 필터를 보존하며 기본 표시는 휘발유다.
- 지도 지역 마커 클릭은 시도→시군구→상세 축척으로 이동한다. 날씨 대표 선택은 해당 실제 지점 상세를 연다.

## 날씨 상세

첨부 화면의 현재 기온·상태, 최저/최고, 체감·풍속/풍향·습도·자외선·미세/초미세먼지 카드와
시간별 기온·강수확률·강수량·습도·풍속/풍향을 반영한다. 관측이 없는 항목은 미제공이며 어제 대비나 체감 값을 임의 산출하지 않는다.
시간은 한국 시간이며 자정 날짜와 강수확률0을 보존한다. 시간별 예보는 제공처·데이터셋·발표 시각이 같은 묶음을 선택한다.
표는 최대24시각이며 실제 응답이 적으면 받은 구간만 보인다. 각 열의 제목에서 제공처/발표 시각을 확인할 수 있다.
풍속 km/h는 m/s로 환산하고 풍향은 방향과 각도를 함께 표시한다. 지표 카드는 화면 폭에 맞춰 줄바꿈하고 시간별 예보만 수평 스크롤하며 페이지를 넓히지 않는다.
