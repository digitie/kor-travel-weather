# 날씨 예보 차트와 지도 상세 개선

## 변경 범위

사용자21개 요구 가운데 Weather 상세정보 배치·예보 선 그래프·행정구역 표시 이름 축약과
초기 지도 DOM·카탈로그 취소 경로를 먼저 변경한다. 별도 빌드 작업자가 머지한 #227의
Node22.23.1·npm12.0.1·공통 도구 계약을 보존한다.

- 공식 EvilCharts의 ECharts 선 그래프를 동적 import로 표시한다. 현재·내일·부가정보·시간별 표의 데이터와 순서는 유지한다.
- 영하·0℃를 보존하고 누락·비정상 단위·2시간 초과 간격을 잇지 않는다. 전체 KST 날짜/시각을 tooltip 데이터에 남긴다.
- 측정 지점은 위치·데이터 출처 정보 버튼 안으로 옮긴다. 링크를 누르면 선택 위치 대신 실제 측정 지점 좌표로 이동한다.
- 갱신·선택 위치로 이동 버튼은 상세 창 상단의 접기 조작 옆에 둔다. 측정자료 목록은 시간별 예보 아래에 둔다.
- 지도 행정구역명은 표시만 인천·충북·파주 등의 짧은 이름을 사용한다. 원래 명칭·필터·지역 식별자는 유지한다.
- 목록 탭을 열 때만 전체 위치 버튼을 만든다. 지도 인스턴스는 계속 유지하고 지도 모드의 숨은 전체 목록 DOM을 제거한다.
- 카탈로그 재조회·페이지 이탈 시 이전 요청을 취소한다. 늦게 끝난 이전 요청이 현재 결과·오류·loading을 덮지 않는다. 취소 후 다음 페이지도 전송하지 않는다.

## 검증과 실행 범위

이전 원문에는 집중30PASS와 타입 검사 성공이 있다. 이번 최종 소스의 검증은 별도 실행 원문으로
구분한다. 사용자 최신 지시로 테스트는 수행하며 이미지·Next production 빌드와 배포는 수행하지 않는다.
소스 검토만으로 모바일·PC 실제 그래프 및 지도 타일의 동작이나 운영 지연 개선율을 보장하지 않는다.
