# 로드 완료 후 날씨 마커 물음표 수정

## 원인과 재현

2026-11-16 공개 API의 시도 대표 지점 3개를 읽기 전용으로 관측했다. 두 지점의 실황 배열에는 KMA T1H·PTY=0이 있고 하늘 상태는 같은 응답의 현재 시간대 예보 SKY=3/4에 있었다. `markerValues`가 실황 배열이 비어 있지 않으면 예보 전체를 제외하므로 날씨 분류는 unknown, 지도 아이콘은 `?`가 됐다. 무강수는 맑음의 근거가 아니다.

원본 응답에서 필요한 필드만 남긴 비공개 작업 원장과 회귀 시험으로 확인했다. 외부 제공처 호출·수집·DB 쓰기·환경 변경은 하지 않았다.

## 수정 계약

- 실황의 강수·날씨 코드를 우선한다.
- 실황만으로 하늘 상태를 판단하지 못할 때, 이미 받은 예보에서 현재 시각의 정시부터 현재 시각까지에 해당하는 SKY만 보완한다.
- 맑음·구름만 보완하며 접근성 이름에 `현재 시간 예보`를 표시한다. 미래·이전 시간·잘못된 시각과 예보 강수/기온은 실황에 섞지 않는다.
- 현재 시간 SKY도 없으면 unknown을 유지한다. 실황만을 선택해 예보가 응답에 없는 경우도 같다.
- 예보만 선택했을 때의 가장 이른 동일 대상 시각 선택, 실황 기온 선택, API 계약·요청 수·캐시는 바꾸지 않았다.

## 검증

수정 전 새 회귀 중 맑음·구름3·흐림4의 3개가 실제 unknown으로 실패했다. 수정 후 기존 풍랑/뇌우 분리·실황 우선·미래 비/기온 제외를 포함해 지도 관련 5개 파일61개가 WSL과 네트워크 없는 Docker에서 각각 통과했다. 두 실행은 동일 시험이므로 합산하지 않는다. Node22.23.1/npm12.0.1을 사용했고 집중 lint·타입·의존성 검사·전체 Doctor도 통과했다.

UI 배치·버튼·지도 엔진 변경은 없다. 운영 웹 재배포와 실제 PC/모바일 새 이미지 수용은 이번 소스 수정의 완료로 주장하지 않는다. 정확 후보 CI와 소스 머지 결과는 이번 PR 원장을 따른다.
