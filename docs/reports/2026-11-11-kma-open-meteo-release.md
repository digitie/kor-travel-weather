## 참조 무결성과 실패 정산

초기 큰 삭제 묶음의 SQLSTATE57014와 보조 검증 경로 오류를 원문에 보존했다.
물리 구간·키 정렬 방식도 실제로 관측했고, 반복 외래키 검사 비용이 커
최종 작업은 대상 부모 행을 먼저 FOR UPDATE로 잠근 뒤 참조를 일괄 검산했다.
이 잠금 아래 Open-Meteo fact와 원천 응답의 각 부모 삭제 문장에 트랜잭션 로컬
`session_replication_role=replica`를 적용했다. 같은 트랜잭션에서 origin 복원과
대상 잔여0을 확인하고 commit했다. 다른 세션의 FK 검사는 계속 적용된다.
기존 child 참조가 있으면 삭제 전에 실패하며, 새 child의 FK 검사는 잠긴 부모 행의
commit을 기다려 재검사한다. 최종 외래키 정의와 앱 역할의 일반 권한을 대조했다.

기존에 완료된 삭제와 원 실패를 보존하며 후속 작업에서 남은 행만 처리했다.
기존 수집의 자연 종료를 확인한 뒤 이미지를 교체했다. 소유한 삭제 보조 작업의 진행 중 문장만
정확한 backend·query identity로 취소해 해당 묶음 rollback 뒤 방식을 조정했다.
