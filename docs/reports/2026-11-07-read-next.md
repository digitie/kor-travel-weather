## 2026-11-08 추가 상태 조회 개선 — 검증·배포 진행

실제 새 API의 현재·일별 export가 각각45초 HTTP 제한을 넘었다. 위치500행은200/304였으나24.84/19.32초였고 상태는17.84초였다. 이 관측을 성공으로 바꾸지 않는다. 호스트4코어에서 load10~11을 관측했지만 CPU·I/O 원인을 단정하지 않는다. 새 수집기 반영은 기존 Root b6a5의 수집 자연 종료를 기다린다. Transport의 실제 지도5000곳16.22/20.86초도 앞선12~13초보다 느렸으며, 국소 CPU 개선을 전체 HTTP 개선으로 과장하지 않는다.
