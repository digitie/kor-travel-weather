# 2026-11-19 — fact 저장의 제한된 COPY 경로

기존 1,000행·26열 fact 저장만 psycopg COPY로 전달한다. 공개 SQLAlchemy `DialectEvents.do_executemany` 이벤트 안에서 처리하므로 caller Session의 트랜잭션, bind processor, statement 계측, DBAPI 오류 변환과 연결 무효화를 유지한다. 엔진별 listener이며 표시한 전체 행 INSERT만 선택한다. ORM 부모 flush·중복 identity 판정·current projection·원천 lineage·재시도·1,000행 상한은 기존 경로다. 스키마·API·수집 스케줄을 바꾸지 않는다.

RETURNING, 부분/default 열, 다른 dialect, 명시 pipeline, 표시 없는 INSERT와 명시 기본 schema 번역은 기존 dialect로 돌려보낸다. 단일 행은 기존 execute 경로다. 독립 리뷰에서 None/빈 문자열 schema 번역과 PostgreSQL search_path 사이의 의미 차이를 발견하여 이 fallback을 추가했다.

## 검증

- 격리된 실제 PostgreSQL DB에서 신규 16건 통과: 0/1/2/1,001행 왕복과 rollback; JSON·유니코드·Decimal·aware datetime·NULL; FK·check·unique·naive datetime의 정확 오류와 batch rollback; statement/error hook; 실제 연결 종료 후 pool 무효화와 다음 트랜잭션 복구; unflagged/RETURNING 및 기본 schema 번역 fallback; 공개 ingest의 lineage·멱등성·current projection; 실제 2행 COPY의 55P03 잠금 충돌 후 기존 fresh-transaction 재시도.
- 각 실행은 기존 로컬 PG fixture의 UUID DB만 생성·삭제했다. 운영 DB 쓰기·수집 강제 실행·캐시 삭제는 없다. 전체 저장소 CI와 실제 이미지 적용은 PR/배포 수용에서 별도로 확인한다.
- 동일 1,000행 26열을 5개 교대 쌍으로 비교한 저장 단계 중앙 시간은 기존 pipeline 304.25ms → 이벤트 COPY 102.21ms, 프로세스 CPU 29.69 → 16.59ms였다. 저장 결과 전체 해시는 일치했다. 합성 로컬 저장 단계의 66.4% 시간·44.1% CPU 감소이며 운영 전체 수집이나 첫 조회 개선율은 아니다. 이 비교는 기본 schema 경로였으므로 리뷰 후 기본 schema 번역 fallback은 측정 경로를 바꾸지 않는다.

공개 이벤트 계약: [SQLAlchemy Core Events](https://docs.sqlalchemy.org/en/20/core/events.html#sqlalchemy.events.DialectEvents.do_executemany). 정확 source/test 해시·원시 시험과 비교 기록은 비공개 배포 증거 `weather-fact-copy-work`에 보존한다.
