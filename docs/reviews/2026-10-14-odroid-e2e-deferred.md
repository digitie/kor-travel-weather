# Odroid 장애에 따른 운영 E2E 미실행과 머지 기록

## 현재 상태

2026-10-14 사용자 보고에 따르면 운영 Odroid 호스트가 중단됐다. 이에 따라 이번 변경의
운영 live E2E와 브라우저 UI E2E는 실행하지 못했다. 이 기록은 E2E PASS가 아니며,
로컬 단위·계약·빌드·CI·두 독립 소스 리뷰 통과가 운영 검증을 대신하지 않는다.

## 이번 머지의 조건

사용자는 Odroid 장애와 E2E 미실행을 명시한 뒤 현재 PR을 머지하고 남은 작업을 계속 진행하도록
지시했다. 이번 PR의 운영 E2E 선행 조건에 대한 명시적 예외이며, 후속 운영 검증의 면제는 아니다.
최종 머지는 현재 소스 및 기록 문서 리뷰와 CI 결과를 확인한 뒤 진행한다.

## 복구 뒤 남은 검증

응답별 JSON byte 예산·부분 게시·재실행 멱등성·실제 수집 실패/복구와 프로세스 메모리를 확인한다. 크기 검사의 추가 Python 할당 계측을 전체 RSS 한도로 해석하지 않는다.

최신 main 커밋·이미지·배포 설정을 새 기준으로 확인하고 실제 로그인 POST/쿠키, API 및
Dagster 화면, 실패·미확인·재시도·복구 동작을 검증한다. 운영 배포·E2E·backfill·수집 검증은
실제 결과를 얻기 전 완료로 표시하지 않는다. 장애 동안 다른 프로젝트의 서비스나 공용 인프라를
강제 재시작하는 방식으로 우회하지 않는다.
