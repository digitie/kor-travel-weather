# ADR-102: W5 전체 목록은 미승인 원천 때문에 503을 내지 않는다

- 상태: 채택
- 결정일: 2026-10-27

## 맥락

W5 `daily-summaries` 전체 목록(location_id 없음)은 위치별 관측 원천이 모두 한 번은 승인돼야
응답했다. 측정값이 없는 측정소나 응답에서 빠지는 지점은 구조적으로 승인될 수 없어서, 전체
목록이 영구히 503이 됐다. Map은 이 목록을 주기적으로 읽는다.

## 결정

- 전체 목록은 한 번도 승인되지 않은 위치별 관측 원천이 있어도 503을 내지 않고 `stale`로
  표시한다. 그 위치는 승인된 원천만으로 요약하거나 null/`sample_count=0`이다.
  `source_providers`로 어느 원천이 기여했는지 구분한다.
- 단일 위치의 최초 조회는 필수 원천이 미승인이면 503을 유지한다. 선택 원천(청정넷)은 503을
  내지 않는다.
- dataset 전체가 한 번도 승인되지 않았거나 승인 관측이 reducer에 닿지 않은 경우는 기존대로
  이전 집합 `stale` 또는 최초 503이다.
- W5 지표가 없는 AirKorea는 W5 필수 원천에서 뺀다(W2 current 범위는 그대로).

## 검토한 대안

- 모든 원천 승인을 계속 요구: 전체 목록이 영구 503으로 남는다.
- 미승인 위치를 목록에서 제외: 소비자가 위치가 사라진 것과 값이 없는 것을 구분할 수 없다.

## 결과

- 소비자는 전체 목록을 항상 받지만, 일부 위치의 요약이 비어 있거나 일부 원천만 반영될 수 있다.
- [`../reports/2026-10-23-daily-source-eligibility.md`](../reports/2026-10-23-daily-source-eligibility.md)의
  전체 목록 "최초 503" 문장은 이 ADR로 대체됐다.
